Description [src]

Provide new content for the clipboard.

The formats array indicates the list of MIME types in which the content may be read using WPEPlatform.ClipboardClass.read. This array need to be null-terminated, and it is recommended to use g_ptr_array_new_null_terminated() to create suitable values.

The is_local flag indicates whether the content is be provided by WebKit itself.

Important

Custom implementations of this virtual function must chain up to the base implementation.
